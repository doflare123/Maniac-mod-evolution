# Общее колесо выбора

`client/screen/radial` содержит общую отрисовку, наведение, переключение секторов,
подтверждение и отмену. Число секторов определяется списком вариантов.
`RadialSelectionMenu` передаёт заголовок, клавишу, предметы, подписи, цвета,
состояние доступности, дополнительные сведения и обработчик выбора.
Сетевые пакеты и правила применения предметов остаются в модулях классов.

- Хельсинг: удерживать `C`, четыре типа болтов, количество в инвентаре и текущий заряд.
- Течис: удерживать `V`, три типа мин, стоимость маны, время установки и перезарядка.
- Отпустить клавишу или нажать ЛКМ/Enter — подтвердить. Esc/ПКМ — отменить.
- Колесо мыши и стрелки переключают варианты. Центр сохраняет текущий выбор.
- Оба класса используют один экран без паузы мира; управление камерой и перемещением
  во время выбора обрабатывается как у обычного меню Minecraft.
- Недоступность варианта показывается в меню; окончательную проверку применения
  предмета выполняет сервер соответствующего класса.

После объединения веток `SurvivorClass`: Хельсинг — **14**, Течис — **15**.
Внешние команды карт для Течиса должны использовать 15. Пакетный протокол объединённой
сборки — **23**; клиенту и серверу нужна одна версия мода.

Проверки: `gradlew.bat verifyRadialSelection verifyHelsing`.
