# Character card artwork

Helsing, Forester and Engineer use 1024 × 1536 RGBA PNG frescoes in `src/main/resources/assets/maniacrev/textures/gui/frescos/`.
The portraits are used for the character preview backdrop. Separate 2172 × 724 panoramic `helsing_selection.png`, `forester_selection.png` and `engineer_selection.png` images are used by both selection card sizes, following the existing Techies artwork pattern.
The vertical frescoes match `techies.png`: rectangular silver-blue mosaic frames, cyan diamond ornaments and chunky cuboid characters in complete scenes with their equipment.

Generated with the built-in `image_gen` tool. Current vertical style reference: `techies.png`; each character's horizontal selection banner supplies costume and equipment identity.
`CharacterSelectionScreen.FRESCO_DIMENSIONS` must match the actual PNG dimensions.
`CharacterSelectionScreen.SELECTION_FRESCO_DIMENSIONS` must match the panoramic PNG dimensions; the corresponding character classes override `getSelectionFrescoTexture()`.
`tools/build_engineer_assets.py` preserves an existing engineer fresco when regenerating equipment previews.
