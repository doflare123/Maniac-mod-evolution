# Производительность атмосферы

Проверено 17.11.2026 на RTX 4070, NVIDIA 621.24, Java 17, Forge 47.2.18.
Время ниже измерено запросами OpenGL `GL_TIME_ELAPSED`. Оно включает проходы
нашей постобработки и копирование результата, но не остальной рендер Minecraft.
Это миллисекунды работы GPU, а не итоговый FPS.

Стоимость самой библиотеки при OFF проверена отдельно:
[Veil в режиме «Отключить»: A/B-проверка](veil-overhead.md).

Для передачи теста другому игроку доступна команда `/mrbench start`:
[инструкция по переносимому бенчмарку](portable-benchmark.md).

## Изменение рендера

В NORMAL и HEAVY объёмный туман и рассеянный свет вынесены в отдельный проход.
При высоте кадра от 1080 пикселей его ширина и высота уменьшены вдвое;
при 3840×2160 объём рассчитывается в 1920×1080. Ниже этого порога буфер
сохраняет полное разрешение. Число шагов интегрирования, рисунок шума,
плотность, цвета, группировка и количество источников сохранены.

Основной проход освещает поверхности и считает контактные тени в полном
разрешении. При восстановлении объёма четыре соседние выборки взвешиваются
по глубине. Если ни одна не соответствует тонкому объекту переднего плана,
шейдер рассчитывает его луч исходным интегратором. Ограничение видимости
до 28 блоков применяется после восстановления, по исходной глубине.
История кадров и временное накопление не используются.

Проверки перекрытия света также завершаются раньше: полностью закрытый луч
не требует следующих проб, а незакрытая проба не требует проверки геометрии
самого излучателя. LIGHT использует прежний простой проход с этими же
упрощениями проверок перекрытия.

## Измерения

Синтетическая сцена, HEAVY, 3840×2160, медиана времени прохода:

| Группы | Контактные тени | Исходный вариант, мс | Новый вариант, мс |
| --- | --- | --- | --- |
| 0 | Нет | 8.20 | 2.77 |
| 10 | Нет | 13.38 | 5.30 |
| 10 | Да | 18.25 | 7.68 |
| 40 | Нет | 21.48 | 9.77 |
| 40 | Да | 32.30 | 13.95 |

В этой сцене каждая группа представляет ряд из четырёх блоков, а не одну
лампу. Оба запуска используют фиксированные камеру, время, геометрию и
источники. Новый запуск использует 30 прогревочных и 41 измеряемый кадр.
Первый исходный запуск использовал 8 прогревочных и 25 измеряемых кадров.
Повторные измерения нового варианта дали 7.0–7.7 мс для 10 групп с тенями
и 11.9–14.0 мс для 40; частоты и фоновая нагрузка влияют на результат.

Дополнительно использована отдельная копия `run/saves/New World2`.
В каждой точке проверены четыре направления камеры в 3840×2160:

| Точка | Переданные группы | Исходный диапазон медиан, мс | Новый, мс |
| --- | --- | --- | --- |
| Последняя позиция, −244.5 / 41 / −22.92 | 29 | 10.50–22.82 | 8.72–9.08 |
| −217.5 / 41 / −8.5 | 64 | 26.24–36.89 | 10.84–13.02 |
| −494.5 / 44 / 18.5 | 1 | 7.37–7.95 | 2.29–2.32 |

Второй участок достигает текущего лимита 64 групп. Оптимизация не уменьшает
этот лимит и не отбрасывает дополнительные лампы. Исходное сохранение
не открывалось клиентом проверки и не изменялось.

Сравнение синтетических PNG в 1080p и 4К: средняя абсолютная ошибка RGB
менее 0.05 уровня из 255, 99-й процентиль максимальной ошибки канала —
1 уровень. Пикселей с ошибкой более 8 уровней не обнаружено. Это проверка
фиксированной сцены; она не означает побитового совпадения во всех мирах.

## Освещение поверхностей и контактные тени на плотном участке

Замер 21.11.2026 на RTX 4070, драйвер NVIDIA 621.24, 3840×2160. Камера
зафиксирована в точке −217.5 / 41 / −8.5, поворот 180°, наклон 0°. Во всех
вариантах передавались 64 группы света. Для каждого варианта записано три
серии по 80 кадров после прогрева. В таблице приведена медиана из трёх
значений каждой метрики. Запрос OpenGL охватывает всю постобработку
атмосферы, включая копирование результата.

| Режим | Свет на поверхностях | Контактные тени | Медиана, мс | p95, мс |
| --- | --- | --- | ---: | ---: |
| LIGHT | Вкл. | Выкл. | 6,77 | 6,95 |
| NORMAL | Вкл. | Выкл. | 7,57 | 7,79 |
| HEAVY | Вкл. | Вкл. | 13,20 | 13,51 |
| HEAVY | Выкл. | Выкл. | 5,14 | 5,36 |
| HEAVY | Вкл. | Выкл. | 9,00 | 9,16 |
| HEAVY | Выкл. | Вкл. | 7,58 | 7,81 |

В HEAVY освещение поверхностей при выключенных тенях добавило 3,81 мс.
Контактные тени при включённом освещении поверхностей добавили 4,19 мс.
При выключенном освещении поверхностей тени в тумане добавили 2,44 мс.
Оценка вклада теней на поверхностях по разнице этих двух замеров составила
1,76 мс. Для каждого эффекта использована медиана разностей между
вариантами в одной серии.

## Повторение проверок

Команды выполняются с Java 17 и существующим Gradle-кэшем. При пропуске
`processResources` init-скрипт копирует актуальные шейдеры в ресурсы клиента.

```powershell
.\gradlew.bat compileJava verifyAtmosphere verifyAtmosphereLightCache -x processResources --no-daemon
.\gradlew.bat -I tools/atmosphere-render.gradle -PatmosphereProbeWidth=3840 runClient -x processResources --no-daemon
.\gradlew.bat -I tools/atmosphere-render.gradle -PatmosphereBenchmark=current runClient -x processResources --no-daemon
.\gradlew.bat -I tools/atmosphere-render.gradle -PatmosphereWorldProbe runClient -x processResources --no-daemon
```

Графический набор проверяет видимость 6/20/28/30/100 блоков, низовые клубы,
однопиксельный передний объект, цветные источники, тени стен и потолочных
излучателей, зажигалку, стыки световых ореолов и настройки графики.
Нужно проверить строку `Atmosphere render probe PASSED` в журнале:
сам код завершения процесса не доказывает прохождение графических проверок.

В этой проверке прошли `compileJava`, `verifyAtmosphere`,
`verifyAtmosphereLightCache`, графический набор в 960×540 и 3840×2160,
а также `Atmosphere world probe`. В 4К однопиксельный объект сохранил
контраст 217 уровней, изменение соседнего фонового пикселя составило 0.

Синтетический замер создаёт `run/atmosphere-client/benchmark-current/gpu.csv`
и PNG. Если существует `benchmark-baseline`, он дополнительно сравнивает
пиксели с соответствующими исходными кадрами.

Для замера существующего мира сначала подготовьте копию в
`run/atmosphere-map-client/saves/perf-map`, затем запустите:

```powershell
.\gradlew.bat -I tools/atmosphere-render.gradle -PatmosphereMapBenchmark=current runClient -x processResources --no-daemon
```

Этот тест предназначен для указанного мира: три координаты приведены в
таблице и заданы в `AtmosphereMapPerformanceProbe`. Он меняет положение
игрока и его режим только в копии, сохраняет PNG и CSV в
`run/atmosphere-map-client/benchmark-current`, затем закрывает клиент.

Для шести вариантов в одном ракурсе плотного участка используйте ту же копию:

```powershell
.\gradlew.bat -I tools/atmosphere-render.gradle -PatmosphereMapBenchmark=dense-light-breakdown -PatmosphereMapLightBreakdown runClient -x processResources --no-daemon
```

Результаты серий сохраняются в
`run/atmosphere-map-client/benchmark-dense-light-breakdown/light-breakdown.csv`.

Для локального сравнения с прежними ресурсами доступен
`-PatmosphereReference`: он читает заранее сохранённый каталог
`build/atmosphere-perf/original-shaders/pinwheel`. Если снимка нет, запуск
завершится ошибкой. Этот каталог и результаты замеров не входят в Git.
